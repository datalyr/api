# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub:

1. Open the [Security tab](https://github.com/datalyr/api/security) of this repository.
2. Select **Report a vulnerability**.
3. Describe the problem, the affected versions and the steps to reproduce it.

We reply to the report in the advisory. We publish a fix and an advisory when the problem is resolved.

## Supported versions

We fix security problems in the latest published version of `@datalyr/api`.
